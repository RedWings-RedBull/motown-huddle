# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful, be constructive, assume good faith, and keep the rivalry on the field.
Harassment, discrimination and personal attacks are not tolerated anywhere in this project's spaces
(issues, pull requests, discussions).

Report concerns privately to the maintainer via GitHub (`@RedWings-RedBull`). Reports are handled
confidentially and in line with the Covenant's enforcement guidelines.
